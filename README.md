# SGODA-PUINAVE

**Sistema de Gestión de Objetos Digitales de Aprendizaje para la preservación y enseñanza de la lengua Puinave.**

> Tecnología para preservar la memoria del pueblo Puinave.

## Propósito

SGODA-PUINAVE es un ecosistema de software orientado a preservar, documentar, administrar y enseñar la lengua Puinave mediante fichas léxicas digitales, objetos digitales de aprendizaje, recursos multimedia y herramientas de automatización.

## Componentes principales

- Ficha Léxica Digital — FLD.
- Objeto Digital de Aprendizaje — ODA.
- Sistema de Gestión de Objetos Digitales de Aprendizaje — SGODA.
- Centro de Conocimiento Puinave — CCP.
- PMO Digital.
- Auditor del Repositorio.
- SGODA Project Builder.

## Arquitectura tecnológica

- Python.
- FastAPI.
- PostgreSQL.
- Flutter.
- JSON.
- GitHub.
- n8n.

## Estructura general

```text
builder/        Automatización y construcción del proyecto
docs/           Gobierno, arquitectura y documentación
knowledge/      Base de conocimiento
scripts/        Automatizaciones operativas
src/            Código fuente del SGODA y PMO Digital
tests/          Pruebas automatizadas
artifacts/      Evidencias, auditorías e informes generados
```

## Gobierno del proyecto

El proyecto utiliza entregables y controles normalizados:

- SPB — SGODA Project Builder.
- SGD — Documento de Gobierno SGODA.
- ADR — Registro de Decisión de Arquitectura.
- ACT — Acta Técnica.
- PMO — Oficina Digital de Gestión del Proyecto.

## Auditoría y cierre

El Auditor del Repositorio está integrado al PMO Digital y genera:

- SGD-401 — Informe de Auditoría Integral.
- ACT-003.2 — Acta Técnica de Decisión de Cierre.
- Evidencias JSON para trazabilidad automatizada.

El cierre técnico requiere:

1. Pruebas PMO aprobadas.
2. Pruebas Builder aprobadas.
3. Ausencia de hallazgos bloqueantes.
4. Documentación obligatoria presente.
5. Repositorio Git gobernado.
6. Aprobación formal de la PMO Digital.

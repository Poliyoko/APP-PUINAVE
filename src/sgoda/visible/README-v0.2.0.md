# SGODA Visible N v0.2.0

Motor visible parametrizado para una instancia SGODA.

## Principios

- N registros sin limite funcional codificado.
- Una lengua nativa principal por instancia.
- Idiomas auxiliares definidos en configuracion.
- Prefijo e IDs definidos por instancia.
- Fuente lexica parametrizada.
- Almacenamiento multimedia parametrizado.
- Paginacion obligatoria.
- Busqueda sobre N registros.
- Carga de audio bajo demanda.
- Sin codificar Puinave dentro del motor.

## Quality Gates de escala

La version v0.2.0 debe superar:

- regresion de las 20 palabras reales;
- 1003 registros;
- 1501 registros;
- 5000 registros de estres.

El Pilot-20 publicado permanece como linea base
historica y no se modifica durante este desarrollo.

# SGODA Visible Pilot-20

Vertical slice funcional para validacion visible
de las primeras veinte fichas lexicas.

Capacidades:

- listado de fichas;
- busqueda;
- detalle por lexical_id;
- pronunciacion;
- significado en idioma auxiliar;
- reproduccion de audio Puinave;
- navegacion anterior/siguiente.

La identidad lexica depende del ID y no solamente
de la forma escrita.

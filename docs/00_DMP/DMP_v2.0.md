# Documento Maestro del Proyecto SGODA-PUINAVE — DMP v2.0

## 1. Resumen ejecutivo

Construir una plataforma integral, trazable y gobernable para el proyecto SGODA-PUINAVE.

El proyecto cuenta con 9 entregables principales gestionados por el PMO Digital. El avance promedio documentado es 96.67 %.

## 3. Riesgos y acciones

| Riesgo | Nivel | Acción de mitigación |
|---|---|---|
| Desactualización documental | medium | Generar documentos desde el modelo único del PMO antes de cada cierre. |
| Evidencia histórica incompleta en expedientes SPB-001/SPB-004 a SPB-009 | medium | Vincular expedientes completos y registrar fuente de cada evidencia. |
| Duplicidad entre DMP y documentos ejecutivos | low | Usar una única fuente de datos y generadores automatizados. |

## 4. Regla de actualización

Todo cierre de SPB o DMP debe actualizar el modelo único del PMO y regenerar Dashboard, DMP, informe, presentación, catálogo y documento técnico.

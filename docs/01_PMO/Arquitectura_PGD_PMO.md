# Arquitectura — Plataforma de Gobierno Documental PMO

La Plataforma de Gobierno Documental transforma el seguimiento del proyecto en un proceso basado en datos. El Dashboard Ejecutivo, el DMP v2.0, los informes, la presentación institucional, el catálogo ejecutivo y el documento técnico se generan desde `knowledge/project_model.json`.

## Capas

1. Modelo único del proyecto.
2. Dominio PMO.
3. Gobierno y validación.
4. Generadores documentales.
5. Publicación y versionado en GitHub.

## Principio rector

No se mantienen versiones contradictorias de la realidad del proyecto. Toda vista ejecutiva o técnica se deriva del mismo modelo.

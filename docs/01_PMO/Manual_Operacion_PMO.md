# Manual de Operación del PMO Digital

## Actualización ordinaria

1. Actualizar `knowledge/project_model.json`.
2. Ejecutar `python scripts/pmo/generate_governance_platform.py`.
3. Revisar Dashboard, DMP, informe, catálogo y documento técnico.
4. Ejecutar pruebas.
5. Registrar commit y push.

## Regla de cierre

Ningún SPB o DMP se considera cerrado si el modelo PMO, el Dashboard, el DMP, el informe y el catálogo no se actualizan.

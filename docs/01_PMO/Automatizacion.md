# Automatización del PMO Digital

El proceso de publicación ejecuta:

1. Carga del modelo.
2. Validación de gobierno.
3. Generación de Dashboard.
4. Generación de DMP v2.0.
5. Generación de Informe Ejecutivo.
6. Generación de Catálogo Ejecutivo.
7. Generación de Documento Técnico.

La presentación PowerPoint se mantiene como artefacto ejecutivo sincronizado con el modelo.
